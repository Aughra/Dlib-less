# L'atelier du prof

Ce dossier est celui de Claude : les exemples du « je fais », les essais, les démonstrations et les brouillons. Claude n'écrit rien ailleurs sur la machine (ni `/tmp`, ni dossier temporaire du système), et range ou nettoie ici comme il l'entend.

Ce n'est pas le code du projet ni celui des exercices : le code du projet vit dans l'espace de travail cargo (à partir du module 0), les exercices dans [../apprentissage/exercices/](../apprentissage/exercices/).

Le dossier est suivi par git ; les `target/` des projets cargo qu'il contient sont ignorés, comme partout.
